# Report checklist

Suggested report sections:
1. Introduction and research question
2. Dataset description and source
3. Exploratory Data Analysis (EDA)
4. Data preprocessing
5. Methodology and train/test strategy
6. Description of the four models
7. Evaluation metrics and comparison
8. Discussion of results
9. Limitations, ethics, and future improvements
10. Conclusion and references

Do not write performance values or conclusions until the scripts have actually been run.
